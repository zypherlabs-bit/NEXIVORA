# Nexivora Roadmap

## Vision

Nexivora aims to be a modern, open-source office suite that provides a seamless experience across all major platforms while respecting user privacy and freedom.

## Current Status (v0.1.0)

✅ **Core Engines**: Formula, spreadsheet, and document engines implemented
✅ **Cross-platform**: Windows, Linux, and macOS support via Tauri
✅ **Basic Functionality**: Spreadsheet formulas, document editing, and presentation creation
✅ **CI/CD Pipeline**: Automated testing and building

## How You Can Help

We welcome contributions in many areas:

- **Development**: Help implement features, fix bugs, improve performance
- **Testing**: Report issues, test new features, improve test coverage
- **Documentation**: Write tutorials, improve docs, create examples
- **Design**: UI/UX improvements, icons, themes
- **Localization**: Translate Nexivora to your language
- **Community**: Help others, moderate discussions, organize events

## Release Cycle

Nexivora follows a time-based release cycle:

- **Patch releases** (bug fixes): As needed
- **Minor releases** (new features): Every 3-4 months
- **Major releases**: Annually or as needed for breaking changes

## Support Policy

Each major version will be supported for at least 12 months after the next major release. Critical security fixes may be backported to older supported versions.
