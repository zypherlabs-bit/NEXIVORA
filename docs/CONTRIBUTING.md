# Contributing to Nexivora

Thank you for your interest in contributing to Nexivora! We welcome contributions in the form of bug reports, feature requests, documentation improvements, and code changes.

## How to Contribute

### 1. Find an Issue
Check our issue tracker for existing bugs or feature requests. If you find something new, please open an issue first to discuss it.

### 2. Create a Branch
For all code changes, please use a separate branch. Use a descriptive name:
`git checkout -b feature/my-awesome-feature`
`git checkout -b fix/bug-description`

### 3. Make Your Changes
- Follow the project's coding standards.
- Ensure all existing tests pass.
- Add new tests for your changes.

### 4. Submit a Pull Request
- Push your branch to GitHub.
- Open a Pull Request (PR) against the `main` branch.
- Provide a clear description of what you changed and why.

## Guidelines
- **Code Style**: We follow standard Rust formatting (`cargo fmt`).
- **Testing**: All new logic must be accompanied by tests.
- **Documentation**: Update relevant documentation if you change public APIs.
