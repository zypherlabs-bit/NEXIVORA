# Documentation

This directory contains the documentation for Nexivora. The main documentation is written in Markdown and can be built with tools such as mdBook or MkDocs.

## Building the Docs
```bash
# Using mdBook
mdbook build docs
```

## Structure
- `README.md` – Overview of the documentation
- `guide/` – User guides and tutorials
- `api/` – API reference for the Rust crates
